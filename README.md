# Know Your Files: Deep Dive — READ ME FIRST

Welcome back, recruit. New expedition, new tools.

In the Liftoff mission you read a file like this as
raw text. This time, open it in VS Code and press the
Markdown preview shortcut (Shift+Cmd+V on Mac,
Shift+Ctrl+V on Windows). Same kind of file, better
glasses — just like we promised.

## Your mission

The expedition's photo archive arrived in one tangled
folder. We sail at dawn.

1. You already cloned this repo (that is how you are
   here). Open the folder in VS Code.
2. In the Explorer sidebar, find index.html and
   right-click it. Choose "Open in Integrated Browser."
3. The page is broken. That is on purpose.
4. The page itself tells you what to fix: make folders,
   rename files, move them into place — all inside the
   VS Code Explorer sidebar. Rename with a right-click
   (or press Enter/F2). Move by dragging.
5. The preview updates as you fix things.

## Watch out

- One photo is buried inside folders it does not
  belong in. Move it up and out.
- One photo is a stowaway — the manifest never asks
  for it. Not every file belongs. Leave it out of
  your images folder (you may delete it).

## When the page celebrates

Commit your changes and push. The pushed repo is your
submission — git will show every rename and move you
made. That is not an accident. Git tracks what you do
to files. More on that soon.

## Rules

- Do NOT rename index.html. That name is special.
- Move files — do not copy them. No stray duplicates.
- Keep this README where it is.

## Remember the invisible file?

On Liftoff you hunted for a hidden file. This repo has
it too — .gitignore — and here it is not just a
curiosity. VS Code's Explorer shows it plainly (no
hidden-file tricks needed), and git reads it to decide
which files never get tracked. Open it.
